# Reference data permission is separate from software licensing

The TALLBMDeconv R/C++ software is GPL-3. Patient-derived atlas parameters,
donor aggregates, identities, annotations and validation truth are not licensed
by the software licence. The project's current atlas handoff explicitly leaves
public redistribution permission unresolved. These resources are supplied only
in the authorised internal distribution. Public posting requires author/data
owner approval, source-study checks and the appropriate data-use terms.

The public-code archive contains no patient-derived reference, validation data,
private server paths, SSH credentials or 125-patient outputs. It can build and
use user-supplied references. No patient data are uploaded by the package.
